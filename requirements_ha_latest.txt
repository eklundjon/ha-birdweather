# The Home Assistant version CI's "HA latest" job tests against.
#
# Each pytest-homeassistant-custom-component (PHACC) release pins one exact
# Home Assistant version, so pinning PHACC pins HA. This lives in its own file,
# rather than in .github/workflows/test.yml, so Dependabot bumps it with each
# new PHACC release (see dependabot.yml); the bump PR is where a new Home
# Assistant release first gets tested. The 2025.4 minimum stays pinned in
# test.yml, out of Dependabot's reach, on purpose.
#
# PHACC's own Python floor moves with Home Assistant's. When it rises, raise
# the "HA latest" job's python in test.yml and .python-version together.
# Dependabot resolves with .python-version, so it won't propose a PHACC release
# that needs a newer Python than that file says.
